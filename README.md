# 教学管理系统 · 交互原型

面向 30 名教师、200–300 名学员规模的教培机构教学管理系统高保真交互原型。
纯前端单文件实现（HTML + 内联 CSS/JS），无需后端，打开 `index.html` 即可运行。

## 在线演示

- GitHub Pages：https://hhhhu3494.github.io/teaching-management-system/

打开后可选择校长、主管、老师、财务四种身份进入，无需密码。

## 已实现模块

- **工作台**：经营指标、待办事项、营收趋势、合规风控预警，待办可跳转对应列表并返回
- **学生档案 / 课时台账**：分页、搜索、多选、年级与课程匹配、消课记录
- **教务排课 / 课程签到**：班级排课、签到标签、一键签到、课时联动
- **订单收银**：净额口径、支付/退款流水、部分退款与全额退款、分页
- **智能质检**：质检列表、质检日志、复核工作台、风险等级、老师风险排行、会话详情
- **智能问数**：自然语言问答、结果面板、图表、明细抽屉、查询结果导出、对话列表
- **数据报表**：营收折线、课程条形图、学员增长柱状、渠道来源环形图
- **多校区**：A/B 校区数据隔离，校长/财务可切换，主管/老师锁定本校区

## 权限模型

| 角色 | 可见范围 |
| --- | --- |
| 校长 | 全部模块，可切换校区 |
| 主管 | 教学与质检模块，锁定所属校区，可复核 |
| 老师 | 教学相关模块，锁定所属校区，不可复核 |
| 财务 | 报表与订单模块，可切换校区，不可编辑学生 |

## 技术实现

单文件静态页面，无框架、无构建依赖。数据为前端内存模拟数据，刷新后重置。
对外发布的 `index.html` 为压缩混淆版本，用于保护作品表达；作者保留完整源码与提交历史作为原创证明。
